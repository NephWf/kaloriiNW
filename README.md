# kaloriiNW

Открытый дневник калорий и КБЖУ.

Сайт: https://nephwf.github.io/kaloriiNW/

Данные остаются в браузере (localStorage). Сервер не нужен: откройте `index.html` или страницу выше.

## Что умеет

- завтрак, обед, ужин и перекус
- база продуктов в духе ассортимента «Пятёрочки» и свои блюда
- белки, жиры, углеводы, вода и сожжённые калории
- расчёт нормы по формуле Миффлина — Сан Жеора
- статистика за 7 дней
